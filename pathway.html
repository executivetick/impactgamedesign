#CodeToCreate · Game Design Pathway

Four courses. One portfolio. Real games.

The Game Design Pathway prepares students for college and careers in game design, software engineering, simulation and interactive technology.

Pathway overview

Through a progressive four-course sequence, students develop technical expertise in programming, game design, digital graphics, 3D development, project management and interactive software development using industry-standard tools such as Unity and Blender.

Students engage in authentic, project-based learning where they design, create, test and publish games, simulations, educational experiences and other interactive applications. Along the way, they strengthen essential professional skills — communication, collaboration, leadership, project management, critical thinking and problem solving — build a professional portfolio, and have opportunities to earn industry-recognized certifications.

Graduates leave with real-world development experience, a portfolio of professional-quality projects, and a strong foundation for continued education and careers in game development, software engineering, simulation, interactive media, digital content creation and other emerging technology fields.

Course sequence

Each course builds on the one before it.

01

Computer Literacy

No prerequisite · start here

Computer Literacy introduces students to the fundamentals of computer science, problem-solving, web development, programming, data analysis, physical computing and artificial intelligence. Through hands-on learning, students explore how technology solves real-world problems while strengthening creativity, critical thinking, collaboration and digital citizenship. They build websites with HTML and CSS, create interactive games and animations with JavaScript, analyze data, build applications, and explore emerging technologies such as machine learning.

Certification opportunity
  • IC3 GS6 Digital Literacy
02

Game Design & Development Principles

Prerequisite: Computer Literacy

Students explore the complete game development lifecycle through the design, creation, testing and publication of interactive games using industry-standard tools. They learn Unity, C# programming, Blender 3D modeling, game design principles, user interface design, data structures, level design and project management while developing multiple playable games, culminating in a comprehensive final game project.

Certification opportunities
  • Unity Certified User: Artist
  • Unity Certified User: Programmer
03

Introduction to Digital Game Graphics

Prerequisite: Game Design & Development Principles

Students create digital graphics and interactive content for games using industry-standard tools such as Unity and Blender. They develop skills in 3D modeling, animation, technical art, level design, lighting, visual effects and interactive media production while building a portfolio of game-ready assets and interactive projects.

Certification opportunities
  • Unity Certified Associate: Game Developer
  • Unity Certified Associate: Programmer
04

Advanced 3D Game Development & Publishing

Prerequisite: Introduction to Digital Game Graphics

In this capstone course, students design, develop, test, deploy and present interactive 3D experiences using Unity and Blender. Working with real clients and authentic project requirements, they create virtual tours, training simulations, educational games and interactive exhibits while following a professional production pipeline — preproduction, production and postproduction — to plan, build, optimize and showcase a portfolio-ready project.

Career readiness
  • Professional Portfolio
