How to get an access token (once a year)

  1. On github.com click your picture → Settings → Developer settings (bottom of the left menu) → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Name: Game Design Pathway publisher. Expiration: up to a year.
  3. Repository access: Only select repositories → impactgamedesign.
  4. Permissions → Repository permissions → Contents: Read and write. Nothing else.
  5. Click Generate token, copy it, and paste it in step 1 above.

Treat the token like a password: it can change this repository and nothing else. Don't share it or paste it into the website's files. If it ever leaks, delete it on that same GitHub page and make a new one.

Unity WebGL builds

Before building: Player Settings → Publishing Settings → Compression Format: Disabled (or Gzip with Decompression Fallback ticked). The publisher blocks Brotli builds because they won't load on GitHub Pages. Any single file must be under 100 MB.
